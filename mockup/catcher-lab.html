Later phase

Strike/Ball Model

How filmed reps could train a model that calls strikes and balls, and measures how much the catcher's glove work changes the call.

Plan
Step 1 · Film

Same camera, every time

One fixed camera behind the catcher at a set height, plus one from the side. A model learns much faster when the angle never changes.

Step 2 · Label

TrackMan gives the answer

TrackMan's session CSV has exact plate location (PlateLocSide, PlateLocHeight) and the call. Match each row to its clip by time. No API needed.

Step 3 · Train

Ball, glove, catch point

First teach it to find the ball and glove in each frame. Then predict where the pitch crossed and whether it's a strike.

Step 4 · Use

Auto-fill the Zone Game

Uploaded bullpen video lands on the zone by itself. The coach confirms or fixes the call, and every fix becomes new training data.

Labeled pitches so far

0 of a 3,000-pitch first target

This counts every called pitch logged in the Zone Game. Each one with a matching clip becomes a training example.

What to plan for

  • Video alone can't see the 3D zone well. Use TrackMan locations to label the clips, then have the model learn from the video.
  • The most useful output is the framing effect: how often a pitch at the same spot gets called a strike for this catcher compared with average.
  • Expect a few thousand labeled pitches before the calls are reliable. Logging starts in the Zone Game now, so that data is building from day one.
  • Get TrackMan CSV exports from each bullpen session. That's the one thing to set up with the 5 Tool data team.
